# GapProof MVP

보이지 않던 학습·프로젝트·전환 경험을 근거가 있는 역량, 목표직무 격차,
이번 주 행동으로 연결하는 Solar 기반 AI 진로상담 지원 프로토타입입니다.

현재 버전은 대회 범위와 사용자 흐름을 검증하기 위한 **클릭형 MVP**입니다.
Solar 서버 호출 경로는 구현되어 있고, `UPSTAGE_API_KEY`가 없거나 호출이 실패하면
입력 원문에서만 후보를 만드는 규칙 기반 샘플로 자동 전환됩니다. 기관 시스템
연동과 실제 자격 인정은 포함하지 않습니다.

## Prerequisites

- Node.js `>=22.13.0`

## 로컬 실행

```bash
npm install
npm run dev
npm run build
```

브라우저에서 `http://localhost:3000`을 엽니다.

## 5단계 데모 흐름

1. 저장·익명통계 동의 범위를 고른다.
2. 전공 밖 학습과 프로젝트 경험을 입력한다.
3. Solar 샘플이 만든 역량 후보의 원문 근거를 보고 확인·수정·거절한다.
4. 대표직무와의 격차, 이번 주 학습·프로젝트·상담 행동을 고른다.
5. 개인용 GapProof 카드와 상담사용 Gap Brief를 확인한다.

## 제품 원칙

- AI가 적성이나 취업 가능성을 단정하지 않는다.
- 원문 근거가 없거나 사용자가 확인하지 않은 역량은 증명으로 올리지 않는다.
- 원문과 익명 통계 공유는 따로 동의받고, 기록 삭제 진입점을 제공한다.
- Solar 실호출과 샘플 폴백을 화면에서 구분한다.
- 모델이 반환한 인용문이 사용자 원문에 실제로 없으면 해당 후보를 폐기한다.
- 텍스트 입력만으로 만든 후보는 모두 Lv.0 `자기기록·확인 필요`로 시작한다.

## Solar 연결

서버 실행 환경에 다음 값을 둡니다. 키를 브라우저 코드나 저장소에 넣지 않습니다.

```text
UPSTAGE_API_KEY=발급받은_키
SOLAR_MODEL=solar-pro3
```

`POST /api/analyze`는 경험 텍스트를 최대 3,000자까지 받고 최대 3개의 역량 후보를
돌려줍니다. 12초 안에 응답하지 않거나, JSON이 잘못되었거나, 원문과 일치하는 인용이
없으면 추론 결과를 증명으로 사용하지 않고 샘플 폴백을 반환합니다.
