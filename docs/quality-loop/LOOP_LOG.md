## Loop 2 — 아이콘·시각 자산 도입 + 현재/준비 중 구분 + 헤더 CTA 보강

### 수정 전 상태

### 변경 의도
1. 프로젝트에 아이콘 라이브러리가 없어(package.json 확인) 직접 제작한 최소 SVG 11종(`app/components/fact-icons.tsx`)을 하나의 토큰(24x24 viewBox·stroke 1.75·round cap)으로 통일해 도입.
2. 가상 사례 카드 6개 라벨, 홈 "기술·안전·검증" 4카드, `/technology` 보안 6항목에 의미별 아이콘을 추가 — 텍스트는 그대로 두고 아이콘을 스캔 보조 수단으로만 추가(additive).
3. "지금 제공해요"/"다음 단계로 준비 중이에요"를 색상(초록/골드) + 아이콘(체크/시계) + 카드 상단 보더로 3중 구분.
4. `/how-it-works` 12단계를 홈 `.home-steps`와 동일한 번호 배지 패턴으로 전환(새 패턴 발명 없이 기존 패턴 재사용).
5. 헤더 CTA에 미세한 그림자 추가(이미 색으로 구분되던 것을 보강).

### 버그 발견 및 수정
`/how-it-works` 번호 배지 1차 구현에서 `display:grid` + `::before` 조합이 `::before`를 실제 그리드 아이템으로 취급해 본문 문단이 30px 폭 컬럼에 갇혀 세로로 한 글자씩 줄바꿈되는 렌더링 버그 발생. Playwright의 가로 오버플로 검사는 이 버그를 잡지 못함(가로 오버플로가 아니라 좁은 컬럼 내 줄바꿈이었기 때문) — 스크린샷 시각 확인으로만 발견. `position:absolute` 배지로 교체해 해결하고 재확인.
