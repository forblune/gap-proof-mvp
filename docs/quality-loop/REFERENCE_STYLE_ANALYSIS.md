# 참고 사이트 스타일 분석 — GapProof 기준선 대비

**조사일**: 2026-07-26
**방법**: Chrome DevTools MCP로 3개 참고 사이트를 390/768/1024/1440px에서 실제 렌더링 → DOM/computed style/스크린샷 직접 측정. 코드·문구·이미지는 복사하지 않았으며, GapProof 파일은 이 단계에서 수정하지 않았습니다.
**표기 규칙**: 모든 항목은 아래 3단계로 근거 수준을 표시합니다.
- 🟢 **직접 확인됨** — DOM/computed style 값으로 직접 측정한 사실
- 🟡 **반복적으로 나타나 가능성이 높음** — 3개 사이트 중 2곳 이상에서 동일 패턴 확인, 우연이 아닐 가능성이 높지만 3/3 확정은 아님
- 🔵 **시각 결과에서 추정됨** — 스크린샷/시각적 인상에 근거한 해석으로, 반증 가능성이 남아있는 추정

1. `rest.dreamitbiz.com/resources` — AI Reboot Academy의 학습자료 링크 모음 페이지 (마케팅 히어로가 없는 사이드바+그리드형 디렉토리 페이지)

## 1. 사이트별 요약

### 1.1 rest.dreamitbiz.com/resources
- 🟢 화면 모드 토글이 **자동/라이트/다크 3단** 존재 (`data-theme` 속성 전환, 단순 `prefers-color-scheme` 아님). 이 조사 환경에서 "자동"은 다크로 렌더링됨 — 이는 브라우저의 색상 스킴 설정을 따른 결과일 수 있어 "다크가 사이트의 고정 기본값"이라 단정할 수 없음.
- 🟢 라이트 모드도 완성도 높게 별도 구현됨 (bg #FFFFFF, 카드 bg 흰색, border #E5E7EB) — 다크가 유일한 선택지가 아니라 명시적으로 지원되는 두 옵션 중 하나.
- 🟢 5가지 선택 가능한 포인트 컬러 테마(blue 기본/red/green/purple/orange) — 액센트 색상이 고정 브랜드 컬러가 아니라 교체 가능한 디자인 토큰.
- 🟢 카드: bg는 페이지와 동일(구분 없음), 1px border만으로 구분, radius 12px, shadow 없음.
- 🟢 카드 타이포: 제목 15px/700/거의흰색 → 설명 13px/400/회색(rgb 209,213,219) → 도메인 캡션 11.5px/400/동일 회색. 굵기+색상으로 명확히 3단 구분.
- 🟢 아이콘 전부 SVG(11개), 이미지 0개, 이모지 0개.
- 🟢 카드 그리드: 1열(390)→2열(768)→2열(1024)→3열(1440). 사이드바는 768까지 상단 스택, 1024부터 좌측 고정 컬럼.
- 🟢 헤더 내비게이션: 1024 이하에서는 햄버거만 표시, 1440에서만 전체 링크(9개) 노출.

## 2. GapProof 기준선 (재확인)

- 🟢 테마 토글 없음, 고정 크림톤 배경 `rgb(247,243,233)`.
- 🟢 `<main>` 내 모든 섹션(topbar/hero/9×section/final/footer)의 background-color가 **전부 transparent** — 히어로부터 푸터까지 배경색 전환이 **단 한 번도 없음**. 3개 참고 사이트는 전부 최소 1회 이상 뚜렷한 배경 전환이 있었던 것과 대비됨.
- 🟢 H1/H2 font-weight **400**(regular), 참고 사이트의 히어로 보유 2곳(site2 700, site3 800)보다 뚜렷이 가벼움.
- 🟢 **H1/H2 폰트가 Georgia/Times New Roman(세리프)** — 3개 참고 사이트는 전부 산세리프(Noto Sans KR ×2, Pretendard ×1). 게다가 본문 문단(`p`)과 eyebrow 라벨은 **모노스페이스**(SFMono/Menlo/Consolas), 기본 바디는 Arial/Noto Sans KR — 한 페이지에 세리프+모노스페이스+산세리프 3종 서체가 혼재.
- 🟢 eyebrow 라벨(11px/700/letter-spacing 1.32px)은 액센트 컬러가 아니라 본문과 같은 잉크색 — 참고 사이트들(kicker에 액센트 컬러 사용)과 다른 접근.
- 🟢 콘텐츠 max-width 980px, 1440에서 여백 약 230px — 참고 사이트 중 가장 넓은 사이드 여백 비율.
- 🟢 카드 내부 "확인된 행동/역량 후보/더 확인할 것/과장하지 않기/직업 가설/이번 주 작은 실험" 6개 라벨이 전부 동일한 크기/굵기/색 — 참고 사이트들의 "제목-설명-메타를 크기+색으로 3단 구분" 패턴과 대비됨.
- 🟢 헤더 내비: 768px에서 이미 전체 텍스트 링크 노출 — 참고 사이트 3곳 모두 1024까지 햄버거 유지 후 1440에서 노출하는 것과 대비됨(더 이른 전개).
- 🟢 primary 버튼 radius 11px/weight 800/그림자 `rgba(23,36,61,.16) 0 8px 20px` — 이 부분은 참고 사이트들의 "플랫 카드 + 그림자 있는 CTA" 패턴과 이미 유사함(차이 아님, 부합 항목).
- 🟢 아이콘/이모지/사진 없음 — 참고 사이트 패턴과 이미 부합.

## 3. 공통 패턴 추출 (근거 수준 표시)

### 3.1 전체 테마
- 🟡 **"고정 다크"가 아니라 라이트 기반 + 어두운 포인트 섹션, 또는 라이트/다크 토글 제공**. 3곳 중 2곳(site1,2)에 명시적 토글 존재, 3곳 모두 "전체가 균일한 한 가지 밝기"는 아님.
- 🟢 **최소 1회 이상의 뚜렷한 섹션 배경 전환이 3/3 사이트에 존재** (site1: 다크 body vs 로열블루 히어로 밴드 / site2: 다크 히어로 vs 라이트 본문 vs 다크 푸터 / site3: 백-흑-주황-흑-백-흑). GapProof는 0회.
- 🟢 **푸터는 3/3 모두 어두운 톤**(site1은 전체가 다크라 자명하지만, site2·site3는 본문이 밝은데도 푸터만 다크로 되돌아감 — 의도적 "bookend" 패턴).
- 🟡 액센트 색상은 사이트마다 다름(site1·2는 블루 계열, site3는 오렌지+블루+퍼플) — "교수님의 고정 브랜드 컬러"는 없음, 프로젝트별로 톤을 다르게 잡음.

### 3.2 콘텐츠 폭
- 🟡 참고 사이트 중 히어로형 2곳은 GapProof(980px)보다 넓은 본문 폭(1280px, 1480px)을 사용하는 경향.
- 🟢 1440px에서 참고 사이트들의 좌우 여백은 56~80px로 작음(콘텐츠가 화면을 거의 채움). GapProof는 약 230px로 훨씬 넓음 — 3개 참고 사이트 대비 GapProof가 "와이드스크린에서 콘텐츠가 좁게 떠 있다"는 인상을 줄 가능성이 있음.
- 🔵 site1(사이드바형 디렉토리)은 성격이 달라 단순 비교는 어려움 — 폭 비교는 site2·site3 기준이 더 유효.

### 3.3 타이포그래피
- 🟢 **참고 사이트의 히어로 H1은 전부 weight 700 이상**(site2 700, site3 800). GapProof는 400 — 뚜렷한 차이.
- 🟢 **참고 사이트 3/3 모두 산세리프**(Noto Sans KR ×2, Pretendard). GapProof는 헤딩에 세리프(Georgia), 본문/라벨에 모노스페이스 — 3개 참고 사이트 어디에도 없는 서체 조합.
- 🟢 **카드 내부 위계는 3/3 모두 "제목(크게/굵게/진한색) → 설명(작게/일반체/회색) → 메타(가장 작게/회색)"의 크기+색상 이중 구분**으로 구현됨. GapProof의 밀도 높은 카드(가상 사례 3가지)는 이 이중 구분이 없음.
- 🟡 kicker/eyebrow 라벨에 액센트 컬러를 쓰는 경향(site2·3에서 확인, site1은 유사 사례 없음) — GapProof는 잉크색만 사용.
- 🔵 negative letter-spacing(큰 제목의 자간을 좁힘)은 site2(-0.84px)·site3(-2.106px)에서 뚜렷, site1은 h2급(-0.56px)만 확인 — 큰 디스플레이 타이포일수록 자간을 좁히는 경향으로 보이나 표본이 작음.

### 3.4 시각적 위계
- 🟢 CTA 버튼은 3/3 모두 **배경과 반전된 고대비 처리**(어두운 배경엔 흰/밝은 버튼, 밝은 배경엔 진한 버튼)로 시선을 확실히 붙잡음.
- 🟡 primary CTA에 그림자(2/3, site1은 없음)를, 그 중 site3는 버튼색과 매칭된 글로우 그림자까지 사용 — "버튼을 띄워 보이게 하는" 경향.
- 🟢 카드 내부 정보는 3/3 모두 역할별(제목/설명/메타, 혹은 site3의 kicker/제목/설명/통계)로 시각적으로 분리되어 한눈에 스캔 가능.

### 3.5 색상과 컴포넌트
- 🟢 3/3 모두 **사진/이모지 없이 아이콘(SVG 또는 아이콘 폰트)만으로 시각 요소 구성**.
- 🟡 카드 radius는 12~26px 범위(사이트마다 다름, "정답"은 없음) — GapProof의 11px은 이 범위에 근접해 크게 벗어나지 않음.
- 🔵 글래스모피즘(backdrop-blur)은 1/3(site2)에서만 확인 — 시그니처 기법은 아니고, 부분적 장식 기법으로 보임.
- 🟡 그라데이션은 히어로 배경 또는 CTA 버튼 등 "포인트"에 한정적으로 사용되는 경향(2/3에서 확인) — 전체 배경을 그라데이션으로 채우진 않음.

### 3.6 콘텐츠 밀도
- 🔵 카드 설명 길이는 사이트마다 다름(site1·2는 1줄 요약, site3는 문단형) — "항상 짧게"가 교수님의 고정 원칙은 아닌 것으로 보임. 콘텐츠 성격(링크 모음 vs 커리큘럼 상세)에 따라 밀도를 조절하는 것으로 추정됨.
- 🟢 다만 밀도가 높을 때(site3)조차 **긴 텍스트 블록 사이에 색깔 있는 풀블리드 섹션을 "숨 고르기" 구분자로 배치**해 지루함을 완화 — GapProof는 9개 섹션이 전부 같은 배경이라 이 호흡 조절이 없음.

### 3.7 반응형
- 🟢 **헤더 내비게이션이 1024px까지 햄버거로 collapse, 1440에서만 전체 노출되는 패턴이 3/3 사이트에서 동일하게 확인됨.** GapProof는 768px에서 이미 전체 노출 — 유일하게 다른 사이트.
- 🟡 카드 그리드는 전부 "390에서 1열 시작 → 1440에서 3~4열 도달"이라는 큰 흐름은 같지만, 중간 단계(768/1024)의 정확한 열 수는 사이트마다 다름 — 세부 브레이크포인트에 고정 공식은 없음.

## 5. 가설 검증

3명의 독립 심사자(동일 원본 증거 파일만 제공, 서로의 답을 보지 못한 상태)가 각각 신뢰도를 산정했습니다. 세 심사자의 최종 판정은 세 가설 모두에서 **놀랍도록 일치**했습니다.

| 가설 | 심사자1 | 심사자2 | 심사자3 | 평균 | 종합 판정 |
|---|---|---|---|---|---|
| **A.** 교수님은 전체 다크 테마를 선호한다 | 낮음 (15%) | 낮음 (15%) | 낮음 (12%) | **~14%** | 🔴 **낮음 — 기각에 가까움** |
| **B.** 교수님은 밝고 어두운 섹션을 혼합해 대비를 만든다 | 높음 (72%) | 중간 (58%) | 높음 (74%) | **~68%** | 🟡 **중간~높음 — 조건부 지지** |
| **C.** 교수님은 테마보다 시각적 위계·타이포·정보 구조를 더 중시한다 | 높음 (82%) | 높음 (78%) | 높음 (85%) | **~82%** | 🟢 **높음 — 가장 강하게 지지됨** |

**가설 A (전체 다크 선호) — 기각에 가까움.** 3명 전원이 독립적으로 반증 근거를 찾았습니다: Site2(ai-prompt)는 기본값이 라이트, Site3(bootcamp)는 애초에 테마 토글 자체가 없고 기본 배경이 흰색, Site1(rest)의 다크 기본값도 "라이트 모드가 같은 토큰 스케일을 반전한 것으로 완성도 높게 구현되어 있어 뒷전 취급이 아니다"라는 점, 그리고 그 다크 외관 자체가 테스트 환경의 OS 자동 설정을 따른 결과일 수 있다는 점이 지적되었습니다. "교수님이 다크를 선호한다"보다는 "다크를 옵션으로 능숙하게 다룰 뿐"이라는 해석이 더 정확합니다.

**가설 B (밝음/어두움 혼합으로 대비) — 조건부로 지지되나 만장일치는 아님.** Site2·Site3에서는 매우 뚜렷합니다(Site3: 흰-흰-검-주황-검-흰-흰-흰-검 순 섹션 전환, Site2: 라이트 기반 + 다크 히어로/푸터 "북엔드"). 다만 심사자 전원이 Site1을 예외로 짚었습니다 — Site1의 유일한 톤 차이(로열블루 배너 vs 근접-블랙 바디)는 "둘 다 dark family"라 진짜 라이트/다크 혼합이 아니라는 점입니다. 이 때문에 "3/3 확정"이 아니라 "2/3 명확 + 1/3 방향은 다르지만 반박하지 않음" 수준으로, 중간~높음 사이에 판정이 갈렸습니다.

**가설 C (테마보다 위계/구조 중시) — 가장 강한 근거.** 3개 사이트는 테마 구현 방식이 완전히 다름(3단 토글+다크 기본 / 2단 토글+라이트 기본 / 토글 없음)에도 불구하고, 타이포 위계(굵기 대비, 특히 Site3의 H1 800 vs H2 300), 카드의 제목/설명/메타 3단 구분, 액센트 컬러의 기능적 재사용(장식이 아니라 방향성 신호), 그리고 3/3 동일한 내비게이션 반응형 붕괴 패턴이 공통적으로 유지됩니다. GapProof는 테마 자체는 문제 삼을 것이 없는 단일 크림톤임에도 H1·H2가 동일 weight(400)이고 카드 내 라벨이 무차별적이라는 점이 대조군으로 인용되어, "문제의 핵심은 테마 색이 아니라 위계·구조"라는 해석에 힘을 실었습니다.

GapProof는 이미 primary CTA에 "다크 네이비 배경 + 흰 텍스트"라는 반전(inverted) 로직을 쓰고 있어, 이를 히어로·footer로 확장하는 것은 개념적으로 큰 도약이 아니라 기존 로직의 자연스러운 확장이라는 점도 세 심사자 모두 근거로 들었습니다. 밝은 테마 개선형은 안전하지만 핵심 피드백(섹션 대비 부재)을 비켜가고, 전체 다크형은 참고 사례가 전혀 없는 데다 작업 범위 대비 근거가 가장 약합니다.

## 7. 조사 한계

- 표본이 3개 사이트로 작습니다. "3/3"이라 표기한 항목도 통계적 확정이 아니라 "지금까지 관찰된 범위에서 예외 없음" 수준으로 읽어야 합니다.
- Site1은 마케팅 히어로가 없는 리소스 디렉토리 페이지라, 히어로/카드 그리드 관련 비교에서는 site2·site3보다 참고 가치가 제한적입니다.
- "자동" 테마 모드가 다크로 렌더링된 것은 조사에 사용한 브라우저 환경의 색상 스킴 설정에 영향받았을 가능성이 있어, 실제 방문자 대다수에게 무엇이 기본으로 보이는지는 별도 확인이 필요합니다.
- 가설·방향 점수는 동일한 4개 근거 파일만 본 독립 심사자 3인의 평균이며, 교수님 본인의 실제 의도를 직접 확인한 것은 아닙니다 — 강한 정황 증거이지 확정된 사실이 아닙니다.
