# GapProof 3분 시연 시나리오 (v1 — Phase A 초안)

목표: 심사위원이 "경험 → 근거 → 확인 → 격차 → 행동"의 닫힌 흐름과 안전장치를 3분 안에 본다.
조작 시간은 자동 리허설 기준 회당 4~5초(`rehearsal-runs.json`) — 발화가 시간의 대부분.

| 구간 | 시간 | 화면 | 말할 것 |
|---|---|---|---|
| 오프닝 | 0:00–0:20 | 게이트 화면 | "GapProof는 공백·전환기의 경험을 역량 증거로 바꿉니다. 심사 공유용 접근 코드로 열겠습니다 — 계정 로그인이 아닌 데모 보호 장치입니다." (코드 입력·Enter) |
| 원칙 | 0:20–0:40 | 시작 화면 | "세 가지 원칙 — AI가 진로를 단정하지 않고, 근거 없는 역량은 인정하지 않고, 원문 공유는 사용자가 선택합니다." (동의 체크 → 시작) |
| 경험 입력 | 0:40–1:05 | STEP 1 | "이력서 밖 경험을 그대로 적습니다. 실명·연락처는 필요 없고, 개인정보로 보이면 자동으로 가립니다." (샘플 입력 → 분석) |
| Solar 구조화 | 1:05–1:30 | STEP 2 | "Solar가 역량 후보와 '원문 인용'을 만듭니다. 원문에 없는 인용은 서버가 폐기합니다. 상단 배지가 실연결/샘플을 구분합니다." |
| 사용자 확인 | 1:30–1:55 | STEP 2 | "AI 제안보다 사용자의 확인이 먼저입니다. 하나는 확인, 과장된 하나는 거절하겠습니다 — 거절은 결과에서 빠집니다." (확인 1·거절 1 → 다음) |
| 격차·행동 | 1:55–2:20 | STEP 3 | "목표 직무와 비교해 우선 격차를 점수로 보여주고, 이번 주 행동 하나만 고르게 합니다." (행동 선택 → 만들기) |
| 결과 | 2:20–2:45 | STEP 4 | "확인된 역량만으로 만든 개인 증거 카드와 상담사용 Gap Brief입니다. 생성 날짜가 남고, 인쇄와 링크 공유(개인정보 미포함)가 됩니다." |
| 클로징 | 2:45–3:00 | STEP 4 | "기록 삭제로 모든 입력이 지워집니다 — 서버에는 애초에 저장하지 않습니다. 미래를 정해 주는 AI가 아니라, 다시 움직이게 하는 AI입니다." |

## 리스크 대비

- Solar 실연결 지연·실패 시: 화면이 자동으로 샘플 폴백을 명시 표시 → "실패도 정직하게 표시합니다"로 전환 멘트.
- 질문 대비 화면: /how-it-works(파이프라인·증거등급), /technology(보안·검증).
- 백업: 사전 캡처(docs/evidence)·인쇄 PDF.

## Phase B 보강 예정

실기기(모바일) 시연 리허설, 실연결 상태 시연 문구, 발화 포함 실측 5회(회당 시간 기록).
