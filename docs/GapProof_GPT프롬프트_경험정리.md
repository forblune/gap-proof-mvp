# GapProof — "GPT로 내 경험 정리하기" 프롬프트

## 이 프롬프트의 역할
사용자가 **이미 쓰던 ChatGPT/Claude(자기 기록이 쌓여 있는)** 에 아래 프롬프트를 붙여넣으면,
AI가 그 사람에 대해 아는 내용을 바탕으로 **GapProof의 `[내 경험]` 칸에 그대로 붙여넣을 정리글**을 만들어 줍니다.
그 결과를 복사해 STEP 1에 붙이면 분석이 시작돼요.

→ 사이트의 **"GPT 프롬프트 복사"** 버튼이 복사하는 내용(`GPT_PROMPT`)으로 사용.
(기존 프롬프트는 GPT가 "분석"을 하게 돼 있었는데, 이제 "입력글 생성" 역할로 바뀜)

---

## 프롬프트 (아래 블록 전체를 복사해서 붙여넣기)

```
너는 내 경력·학습 기록을 정리해주는 조수야. 우리가 나눈 대화와 네가 나에 대해 아는 내용을
바탕으로, 진로·역량 분석 사이트의 "[내 경험]" 입력칸에 그대로 붙여넣을 정리글을 만들어줘.

규칙:
1) 내가 실제로 하거나 배운 것만 써. 확실하지 않으면 넣지 말고, 부풀리거나 지어내지 마.
2) 각 항목은 '무엇을 / 어디서(맥락) / 무엇을 했는지(역할·결과물)'가 드러나게 사실 위주로.
3) 포함할 것: 전공·학교 활동, 독학·수강한 것, 만든 프로젝트·결과물, 아르바이트·인턴,
   자격증·수료, 동아리·대외활동.
4) 확인 안 되는 날짜·수치는 비워둬. 형용사보다 사실 위주로.
5) 출력은 사이트에 바로 붙일 수 있게 불릿 없이 자연스러운 문단으로, 300~600자.
6) 나에 대해 아는 게 부족하면, 먼저 전공·학습·프로젝트·알바·자격을 묻는 짧은 질문 5개만 해줘.
   내가 답하면 그때 정리글을 만들어줘.

설명·머리말 없이, 정리글 본문만 출력해.
```

---

## 사이트 흐름
1. 사용자가 STEP 1에서 **"GPT 프롬프트 복사"** 클릭 → 위 프롬프트가 복사됨
2. 쓰던 GPT/Claude에 붙여넣기 → AI가 사용자 기록 기반으로 **경험 정리글** 생성
3. 그 정리글을 복사 → GapProof `[내 경험]` 칸에 붙여넣기 → 분석 시작

## 안내 문구(버튼 옆/복사 알림)에 넣을 카피
> "쓰던 GPT에 붙여넣으면, 당신 기록을 바탕으로 여기에 넣을 **경험 정리글**을 만들어줘요.
> 그 결과를 복사해 아래 [내 경험]에 붙여넣으세요."
