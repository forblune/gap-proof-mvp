# GapProof 3분 시연 대본

준비물: RC 배포 URL(승인 후) 또는 로컬 RC, 데모 코드, 안정된 네트워크. 시작 전 "새 분석 시작하기"로 깨끗한 상태 확인. 오프닝은 **코드 없는 샘플**로 시작해 심사자가 그대로 따라올 수 있게 한다.

시연용 경험 문단(개인정보 없음):
> 항공물류를 전공했고 집에서 AI 수학과 웹을 독학하며 팀 프로젝트로 물류 데이터 대시보드를 만들었습니다. 노션에 학습 기록을 남겼습니다.

## 0:00~0:20 — 문제

- **말**: "경력 공백이 있는 청년은 '뭐가 부족한가'만 듣습니다. GapProof는 반대로 묻습니다 — 당신이 이미 가진 것 중 증거가 되는 건 무엇인가."
- **클릭**: 홈에서 [샘플로 둘러보기](코드 불필요) — 심사자도 같은 화면을 바로 열 수 있음을 언급
- **화면**: 게이트 카드(최종 브랜드 로고) → 첫 화면 "공백을 지우지 않고, 증거로 바꿉니다."
- **실패 시**: 게이트 503/429가 뜨면 "접근이 몰릴 때는 잠시 대기하도록 막아둔 화면입니다"라고 소개하고 새로고침 후 재시도.

## 0:20~0:40 — 차별점

- **말**: "GapProof는 합격 가능성이나 적성을 판정하지 않습니다. 화면 아래에 항상 '판정이 아닙니다'라고 적혀 있습니다. 대신 AI 제안을 사용자가 검증해 '증거'로 만듭니다."
- **클릭**: 없음(포인터로 푸터 고지와 헤더 배지 가리키기)
- **화면**: STEP0 — 푸터 "취업 또는 적성 판정이 아닙니다", 헤더 모델 선택(Pro 3 기본)
- **실패 시**: 해당 없음(정적 화면).

## 0:40~1:20 — 경험 입력·분석

- **말**: "전공, 독학, 작은 프로젝트 — 흩어진 경험을 그대로 붙여 넣습니다. 이메일·전화번호가 섞여 있어도 전송 전에 자동으로 가려집니다. 분석은 Upstage Solar가 합니다."
- **클릭**: 동의 체크 → [샘플 여정 시작하기] → 경험 문단 붙여넣기 → [내 경험에서 가능성 찾기]
- **화면**: STEP1 입력 → 로딩 스켈레톤 → STEP2 후보 카드
- **실패 시(핵심 대체 경로)**: 카드 상단 배지가 "**Solar 샘플 데모**"로 뜨면 그대로 진행하며 말한다 — "지금은 실제 연결이 아니라 **규칙 기반 샘플 결과**입니다. 화면이 스스로 샘플임을 밝히는 것까지가 설계입니다. 실제 연결 시에는 이 자리에 'Solar 실연결·모델명'이 표시됩니다." (숨기지 말고 배지를 확대해 보여줄 것)

## 1:20~1:55 — 근거 확인

- **말**: "모든 후보 옆에는 제가 쓴 문장이 그대로 인용됩니다. 원문에 없는 역량은 여기 올라오지 못합니다. 그리고 하나도 확인하지 않으면 다음으로 못 갑니다 — 확정하는 사람은 AI가 아니라 저입니다."
- **클릭**: 첫 카드 인용문 가리키기 → 하단 "0개 확인됨·비활성 버튼" 보여주기 → 첫 카드 [맞아요] → 버튼 활성화 확인
- **화면**: STEP2 — 인용 블록, "0개 확인됨" → 확인 후 활성화
- **실패 시**: 후보가 1건뿐이어도 동일 흐름(개수는 중요하지 않다고 언급).

## 1:55~2:30 — 직무 차이·행동

- **말**: "확인된 증거를 기준으로 목표 직무까지 무엇이 비어 있는지, 그래서 이번 주에 뭘 하면 되는지가 나옵니다. '더 공부하세요'가 아니라 실행 단위입니다."
- **클릭**: [격차와 다음 행동 보기] → 격차 목록·추천 행동 스크롤
- **화면**: STEP3 — 우선 격차(Lv 표기), 다음 행동 선택
- **실패 시**: 해당 없음(로컬 연산 단계).

- **말**: "결과는 두 장입니다. 나를 위한 증거카드 한 장, 상담사·기관을 위한 Gap Brief 한 장. 공유 링크에는 개인 결과가 담기지 않고, 인쇄는 배경을 꺼도 읽히게 만들었습니다."
