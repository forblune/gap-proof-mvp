# GapProof 2차 피드백 보고

작성일 2026-07-25 · 운영 https://gapproof.forblune.com · 저장소 github.com/forblune/gap-proof-mvp

## 1. 서비스 한 문장 소개

**GapProof는 흩어진 경험을 지우지 않고, 사용자가 직접 확인한 "증거"로 바꿔 목표 직무까지의 간극과 다음 행동을 보여주는 Solar(Upstage) 기반 진로·역량 분석 도구입니다.** (취업 가능성·적성을 판정하지 않습니다.)

## 3. 핵심 사용자 흐름

**경험 입력 → AI 역량 후보+원문 근거 → 사용자 확인·수정·제외 → 증거 등급 → 목표 직무 차이 → 다음 행동 → GapProof 카드·Brief**

| 단계 | AI가 하는 일 | 사용자가 통제하는 부분 | 왜 필요한가 |
|---|---|---|---|
| 경험 입력 | 없음(전송 전 개인정보 마스킹만 자동) | 무엇을 쓸지, 얼마나 쓸지 | 자기 서술이 분석의 유일한 원천이라는 원칙 |
| 역량 후보+근거 | Solar가 후보를 제안하고 **반드시 입력 원문 문장을 인용** | — | 근거 없는 주장 차단(인용이 원문과 일치하지 않으면 채택 안 함) |
| 확인·수정·제외 | 없음 | 후보마다 맞아요/표현 수정/거절 — **1개 이상 확인 전에는 진행 불가** | AI 제안은 초안일 뿐, 증거로 만드는 건 사용자 |
| 증거 등급 | 링크 유무로 Lv.0(자기기록)~ 등급 산정 | 근거 링크 첨부 여부 | "말"과 "증빙"을 구분해 과장 방지 |
| 직무 차이 | 목표 직무 요구 역량과의 격차 계산 | 목표 직무 선택 | 막연한 불안을 구체적 항목으로 전환 |
| 다음 행동 | 격차 기반 행동 추천 | 행동 다시 고르기 | 분석으로 끝나지 않고 실행으로 연결 |
| 카드·Brief | 확인된 것만 카드로 정리 | 공유·인쇄·삭제·잠금 | 개인용(카드)과 상담사용(Brief)을 분리, 공유 링크에는 개인 결과 미포함 |

## 4. 세심하게 만든 부분 (쉬운 설명)

- **원문 인용을 강제한 이유**: AI가 "그럴듯한 역량"을 지어내는 것을 막기 위해, 입력에 실제로 있는 문장만 근거로 인정합니다. 일치하지 않으면 그 후보는 버립니다.
- **사용자 확정 구조**: 확인 0개면 다음 단계 버튼이 잠깁니다. AI가 아니라 사용자가 결과의 최종 저자가 되게 하는 장치입니다.
- **판정하지 않는 이유**: 합격 가능성·적성 점수는 근거를 만들 수 없고 사람을 위축시킵니다. 화면 하단에 "취업 또는 적성 판정이 아닙니다"를 상시 표기합니다.
- **샘플/실연결 구분**: API 키가 없거나 오류면 "샘플"임을 배지와 문구로 즉시 알립니다. 실패를 실제 결과처럼 보이게 하지 않습니다.
- **개인정보 마스킹**: 이메일·전화번호는 외부로 나가기 전에 [이메일]·[전화번호]로 바뀝니다. 운영 검증에서 화면·서버 로그 모두 원문 0건을 확인했습니다.
- **요청 제한**: 1분에 10회를 넘으면 429와 "1분 뒤 재시도" 안내를 줍니다. 제한 장치가 고장 나면 몰래 통과시키지 않고 503으로 멈춥니다.
- **오류를 숨기지 않는 상태 표시**: 입력이 짧으면 짧다고, 한도가 넘으면 넘었다고 화면에 그대로 말합니다.
- **5개 화면 크기 검증**: 360~1440px을 자동 캡처로 상시 확인합니다(가로 스크롤 0).
- **키보드 접근성**: 마우스 없이 Tab만으로 마지막 카드까지 도달합니다.
- **인쇄 배경 OFF 대응**: 브라우저 기본값(배경 인쇄 안 함)에서도 카드가 흰 배경+진한 글씨로 반전되어 읽힙니다.
- **favicon·PWA·OG·1:1 크롭**: 16px 탭 아이콘부터 카카오톡 정사각 크롭까지 브랜드 요소가 잘리지 않게 배치를 실측으로 맞췄습니다.
- **배포와 롤백**: 배포 전에 되돌아갈 버전 ID를 먼저 기록하고 배포했습니다(이번 배포는 롤백 불필요).

## 5. 품질 검증 결과 (전부 실제 기록)

- 자동 테스트 `npm test` **15/15** (렌더·게이트·마스킹·한도·SEO 포함)
- **운영 배포 성공**: Cloudflare Workers 버전 `cece759c`, 다운타임 0, 롤백 미필요
- **실제 Solar 호출 1회**로 실연결 검증(배지 "Solar 실연결 · solar-pro3", 인용 정합) — 비용 통제 원칙 준수
- **PII 원문 화면·로그 0건**(테스트 전용 가짜 데이터로 검증, Worker 로그 526줄 스캔)
- **429 + Retry-After 60** 운영 실측(유료 호출 0회인 무과금 경로로 검증)
- 보안 쿠키 `HttpOnly; Secure; SameSite=Lax` · 보안 헤더 5종 실측
- 운영 라우트 14종 200·자산(favicon/PWA/OG/manifest) 전부 200, 미구현 경로는 명시적 404
- 5뷰포트 overflow 0 · console error 0 / 인쇄 배경 OFF·흑백·PDF 확인
- **자동화 검증과 수동 검증을 구분**: 실기기(아이폰·안드로이드·카카오톡 실공유·실제 인쇄)는 체크리스트로 남겨 진행 중

## 7. 교수님께 받고 싶은 피드백

1. "확인 0개면 진행 불가" 같은 **사용자 확정 강제가** 실제 상담 장면에서 도움이 될까요, 번거로울까요?
2. Gap Brief(상담사용 1장)를 실제 상담에 쓴다면 **어떤 항목이 더/덜 필요**해 보이시나요?
3. "취업·적성을 판정하지 않는다"는 원칙이 학생들에게 **장점으로 전달될지, 밋밋하게 느껴질지** 궁금합니다.
4. 3분 시연에서 **가장 먼저 보여줘야 할 한 장면**은 무엇이라고 보시나요? (경험 입력 vs 근거 인용 vs 결과 카드)
5. 다음 단계로 **회원저장(#13)과 소셜 로그인(#11)** 중 무엇을 먼저 하는 게 좋을까요?
6. 증거 등급(Lv.0 자기기록~링크 증빙)의 **명칭·단계가 직관적**인가요?
7. 대회 제출물 관점에서 **더 보강하면 좋을 증거 자료**(문서·캡처·데모)가 있을까요?
