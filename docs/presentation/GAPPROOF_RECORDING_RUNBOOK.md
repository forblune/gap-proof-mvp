# GapProof 화면 녹화 Runbook

작성 2026-08-02 · 대상 커밋 `submission-eve-polish`
이 문서 하나만 보고 따라 하면 녹화를 끝낼 수 있게 씁니다.

---

## 0. 한 줄 요약

**주소창에 `https://gapproof.forblune.com/demo?sample=1` 를 넣고, 동의 1개 체크 →
버튼만 순서대로 누르면 됩니다. 접근 코드는 필요 없습니다.**

---

## 1. 녹화 전 준비

### 1-1. 브라우저

- **Chrome** 을 씁니다. Firefox·Safari 에서도 흐름은 같지만 화면 확인은 Chrome 기준으로 했습니다.
- **새 시크릿 창**(⌘⇧N)에서 엽니다. 이유는 아래 "재현성" 항목에 있습니다.
- 확장 프로그램 아이콘·북마크 바가 화면에 나오지 않게 합니다.
  - 북마크 바 숨기기: ⌘⇧B
- 브라우저 확대/축소는 **100%** 로 둡니다. (⌘0 으로 초기화)

### 1-2. 화면 크기

| 용도 | 크기 | 비고 |
| --- | --- | --- |
| **데스크톱 본편(권장)** | **1440 × 900** | 결과 화면의 카드 2개가 나란히 들어가는 가장 작은 크기입니다. |
| 모바일 삽입 컷(선택) | 390 × 844 | Chrome 개발자도구 기기 툴바 → iPhone 14 Pro |

1440×900 을 고른 이유: 1024px 이하에서는 결과 카드가 한 줄로 쌓여 "개인용 증거카드 ↔ Gap Brief"
대비가 한 화면에 안 잡힙니다. 1440 이 그 대비가 살면서도 글자가 작아지지 않는 크기입니다.

### 1-3. 재현성 — 시크릿 창을 쓰는 이유

이 데모는 진행 상태를 **브라우저 localStorage 에 저장**합니다(`gp_draft`).
일반 창에서 한 번 녹화하고 다시 시작하면, 두 번째 촬영은 중간 단계에서 시작되거나
이전에 확인해 둔 역량이 남아 있을 수 있습니다.

- **매 테이크마다 시크릿 창을 새로 엽니다.** 이것만 지키면 항상 같은 화면에서 시작합니다.
- 일반 창을 써야 한다면 촬영 전에: 개발자도구(F12) → Application → Local Storage →
  `https://gapproof.forblune.com` 우클릭 → Clear.

### 1-4. 첫 진입 확인 (촬영 시작 전 30초)

`?sample=1` 로 들어갔을 때 다음이 맞는지 눈으로 확인합니다.

- [ ] 상단에 초록색 띠: "샘플 체험 중 — 실제 분석이 아닙니다."
- [ ] 오른쪽 카드 제목: "샘플로 전체 흐름 보기"
- [ ] 접근 코드 입력칸이 **보이지 않음**
- [ ] 진행바 6단계가 보이고 1번(시작)이 활성

하나라도 다르면 주소를 다시 확인하십시오(`?sample=1` 이 빠지면 코드 입력 화면이 나옵니다).

## 2. 녹화 순서

Shot List 는 별도 문서 `GAPPROOF_RECORDING_SHOT_LIST.md` 에 있습니다.
여기서는 **손이 움직이는 순서**만 적습니다.

| # | 화면 | 조작 |
| --- | --- | --- |
| 1 | 홈 `/` | 위에서 아래로 천천히 스크롤 |
| 2 | 홈 헤더 | 오른쪽 위 **"데모 열기 →"** 클릭 (또는 주소창에 `/demo?sample=1`) |
| 3 | 1단계 시작 | **[필수] 경험 분석을 위한 원문 처리** 체크 → **"샘플로 둘러보기 →"** 클릭 |
| 4 | 2단계 경험 | 입력칸에 샘플 글이 이미 들어가 있습니다. 스크롤 없이 그대로 둡니다 → **"내 경험에서 가능성 찾기"** 클릭 |
| 5 | 분석 진행 | **아무것도 누르지 않고 2.4초 기다립니다.** 3단계가 차례로 체크됩니다 |
| 6 | 3단계 역량 확인 | 첫 카드의 **"✓ 맞습니다"** 클릭 → (원하면 둘째 카드도) → **"다음: 먼저 알아보기 →"** |
| 7 | 4단계 먼저 알아보기 | 자료 카드를 보여준 뒤 **"다음: 격차·행동 보기 →"** |
| 8 | 5단계 격차·행동 | 오른쪽 격차 막대를 보여주고, 행동 카드 하나 클릭 → **"GapProof 만들기 →"** |
| 9 | 6단계 결과 | 증거카드 → Gap Brief 순서로 천천히 보여주고 멈춤 |

### 누르면 안 되는 것 (샘플 모드에서 동작하지 않습니다)

- 4단계의 **"학습 자료 만들기"** — 샘플 모드에서는 실제 AI 호출을 하지 않아
  "시작 화면에서 데모 코드로 입장해 주십시오" 라는 안내가 뜹니다. 촬영에 넣지 마십시오.
- 상단 **"실제 분석으로 전환"** — 접근 코드 화면으로 넘어갑니다.
- 상단 **"모델 변경"** — 필요하면 별도 컷으로 찍고, 본편 흐름 중에는 열지 마십시오.

---

## 3. 각 화면에서 기다리는 시간

| 화면 | 기다림 | 이유 |
| --- | --- | --- |
| 5단계(분석 진행) | **2.4초 고정** | 최소 표시 시간이 코드에 고정돼 있어 매 테이크 같습니다 |
| 그 외 단계 전환 | 약 0.5초 | 화면이 맨 위로 부드럽게 올라간 뒤 멈춥니다 |

단계를 넘길 때마다 화면이 **자동으로 맨 위로 올라갑니다.** 스크롤을 직접 올리지 마십시오 —
겹치면 화면이 두 번 움직여 보입니다.

---

## 4. 다시 찍기

### 특정 Shot 만 다시

- **2~4단계**: 화면 맨 아래 **"체험 나가기"** → 다시 `?sample=1` 로 진입.
- **6단계(결과)**: 결과 화면의 **"행동 다시 고르기"** 로 5단계로 돌아갔다가
  **"GapProof 만들기 →"** 를 다시 누르면 같은 결과가 나옵니다.
- **처음부터**: 시크릿 창을 닫고 새로 엽니다. (가장 확실합니다)

### 결과 화면 날짜

증거카드 오른쪽 아래 날짜는 **녹화하는 기기의 오늘 날짜**로 찍힙니다.
날짜가 이상하면 기기 시간을 확인하십시오.

---

## 5. 문제가 생겼을 때

| 증상 | 대처 |
| --- | --- |
| 접근 코드 화면이 나온다 | 주소에 `?sample=1` 이 빠졌습니다. 다시 넣고 새로고침. |
| 중간 단계에서 시작한다 | 이전 촬영의 localStorage 가 남았습니다. 시크릿 창을 새로 여십시오. |
| "다음" 버튼이 회색이다 | 3단계에서 역량을 1개도 확인하지 않았습니다. "✓ 맞습니다"를 먼저 누르십시오. |
| 분석이 너무 빨리 지나간다 | 최소 2.4초는 보장됩니다. 더 길게 필요하면 그 구간만 편집에서 늘리십시오. |
| 화면이 갑자기 어두워졌다 | 오른쪽 위 테마 토글을 눌렀을 수 있습니다. 다시 눌러 라이트로 되돌립니다. |
| 글자가 너무 크거나 작다 | ⌘0 으로 확대를 100% 로 되돌립니다. |

## 6. 모바일 삽입 컷 (선택)

1. Chrome 개발자도구(F12) → 기기 툴바(⌘⇧M) → **iPhone 14 Pro (390×844)**
2. 개발자도구 패널은 **별도 창으로 분리**해 녹화 화면에 나오지 않게 합니다.
3. 찍을 만한 화면: 홈 히어로 / 3단계 역량 카드(세로 1열) / 6단계 결과 카드.
4. 모바일에서 상단 메뉴는 **"⋯"** 버튼 안에 있습니다.

## 7. 저장

- 파일 이름: `gapproof_screen_YYYYMMDD_shotN.mov`
- 저장 위치: 저장소 **밖**에 둡니다. 예: `~/Movies/gapproof-submission/`
  (이 저장소에는 영상 파일을 커밋하지 않습니다.)
