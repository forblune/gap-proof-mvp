## 문제 정의

`app/lib/engine.ts:74`의 `competencyStrength()`가 산출물·수행 링크 없이 2문항 객관식 퀴즈 통과만으로 증거등급을 Lv.3("수행 확인")까지 올린다. 같은 파일 51행 자체 주석("수행 확인(Lv.2)·기관 확인(Lv.3)은 MVP 범위 밖이므로 임의로 올리지 않는다")과 정면으로 모순되며, 기준서 §6.4("단순 수강 완료가 아니라 수행 또는 산출물까지 연결돼야 증거등급이 오른다")를 직접 위반한다. 연쇄적으로 `app/demo/page.tsx:1195`의 STEP4→5 게이트도 확인 증거 0개 상태에서 퀴즈 통과만으로 통과되어, "확인된 증거만 격차·행동에 연결"이라는 제품의 핵심 약속이 코드 수준에서 깨져 있다.

## 문서 근거

- 기준서 §6.4: "단순 수강 완료가 아니라 수행 또는 산출물까지 연결돼야 증거등급이 오른다."
- 기준서 §7.3: "확인된 역량이 0개면 격차 단계로 진행할 수 없다."
- 원페이지 정의: "사용자가 검증한 증거만 목표 직무의 격차와 이번 주 행동으로 연결하는" — 검증되지 않은(퀴즈만 통과한) 항목은 이 정의의 "검증된 증거"에 해당하지 않는다.
- 상세 근거: `GAPPROOF_ALIGNMENT_AUDIT_2026-07-28.md` §2.4, §2.6, §2.7, §4(CONFLICT 목록).
