# GapProof 제품 기획서 v2

작성일 2026-07-25(RC 개정) · 기준: `rc/professor-feedback`(Gate 0~10 완료) — 운영은 1차 버전 `cece759c` 유지, RC 재배포는 승인 대기
표기 원칙: **[구현됨]** = 현재 운영에서 동작 · **[계획]** = 미구현 미래 항목 (혼동 방지를 위해 전 항목 구분 표기)

## 1. 프로젝트 개요

- 서비스: GapProof — 공백을 지우지 않고 증거로 바꾸는 진로·역량 분석 도구
- 운영: https://gapproof.forblune.com (Cloudflare Workers, 데모 접근 코드 게이트)
- 스택: Next.js(App Router)→vinext→Cloudflare Workers, Solar(Upstage) API
- 상태: 2026 리부트 AI 활용대회 제출 준비(1차 7/29) — 게이트형 공개 데모 운영 중

## 2. 문제 정의

경력 공백·전공 불일치가 있는 청년은 "무엇이 부족한가"보다 "내가 가진 것이 무엇인지"를 정리하지 못해 멈춘다. 기존 도구는 적성·합격 가능성을 **판정**하려 들고, 그 판정에는 근거가 없다.

## 3. 목표 사용자

- 1차: 전공→직무 전환을 고민하는 20대(예: 항공물류 전공 → AI 서비스 기획)
- 2차: 진로상담사·기관(대학 취업지원팀, 청년센터) — Gap Brief로 상담 시간 절약

## 4. 핵심 가치

1. **증거 우선**: 원문 인용 없는 역량 주장은 채택하지 않음 [구현됨]
2. **사용자 확정**: AI 제안은 초안, 확정은 사용자(확인 0개 시 진행 차단) [구현됨]
3. **판정 금지**: 취업 가능성·적성 점수를 만들지 않음(상시 고지) [구현됨]
4. **정직한 상태**: 샘플/실연결 구분, 오류·한도 그대로 표기 [구현됨]

## 5. 사용자 여정 [구현됨]

동의 → 경험 입력(개인정보 자동 마스킹) → Solar 역량 후보+원문 근거 → 사용자 확인·수정·제외 → 증거 등급(Lv.0 자기기록~링크 증빙) → 목표 직무 격차 → 이번 주 다음 행동 → 개인용 증거카드 + 상담사용 Gap Brief → 공유(개인 결과 미포함 링크)·인쇄·삭제·잠금

- 모델 카드 다이얼로그([공식]/[자체]·평가 중), AI 정리 프롬프트·TXT/MD 첨부(업로드 없음)
- 회원·이용량·초대 코드 **로컬 기반**(RLS 실검증) — 운영 공개는 전체 세트+승인 후
- 자동 테스트 32종·e2e 6스위트·QA 스윕

## 10. 기술 구조 [구현됨]

- 시크릿 3종(GATE_ACCESS_CODE·GATE_SESSION_SECRET·UPSTAGE_API_KEY)만 운영 등록
- Rate Limiting API 바인딩 2종(analyze/gate), 보안 헤더 5종, robots/sitemap/manifest 라우트
- 테스트: node:test 15종(빌드 산출물 대상) + Playwright 캡처 하니스

## 11. 개인정보·법률 계획

- [구현됨] 개인 결과 서버 미저장(브라우저 안에서만), 공유 링크에 개인 결과 미포함, PII 마스킹, 익명 통계 공유 안 함 표기

- [계획] 동의 버전 기록(가입 시 어떤 버전 약관에 동의했는지 저장)

## 12. 회원가입·로그인 계획 [계획 — 전부 미구현]

- 이메일 회원가입 + 이메일 인증(링크/코드) + 로그인 + 비밀번호 재설정
- 로그인 상태 유지(세션 연장)·이메일 기억하기(로컬) — **비밀번호 저장 금지**(브라우저 자동완성에 위임, 자체 저장 안 함)
- 소셜: 카카오·Google·Naver 로그인(최소 수집 원칙 — 프로필 사진 등 불요 항목 미요청, #11 구현 시 재검토)
- 가입 방식 안내(이메일 vs 소셜 차이), 동의 버전 기록, **만 14세 이상 확인**
- 회원 탈퇴·데이터 삭제(즉시 파기 원칙)
- 향후 PASS·휴대전화 본인확인 도입 검토(비용·필요성 평가 후)
- 인증 기반은 별도 private repo **forblune-auth-foundation**으로 분리 설계 예정(재사용 목적) — **아직 생성·구현되지 않음**

## 13. 만 14세 미만 초기 이용 제한 계획 [계획]

- 로그인 도입 시 가입 단계에서 만 14세 이상 확인(생년 입력+체크) → 미만은 가입 차단 + 안내
- 법정대리인 동의 체계는 초기 범위에서 제외(수요 확인 후 검토) — 현 게이트 데모는 개인정보 수집 자체가 없음
