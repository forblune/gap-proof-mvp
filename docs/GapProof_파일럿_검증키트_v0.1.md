## 2. 모집 기준

### 청년 참여자

- 최근 1년 안에 취업 준비, 휴식, 진로 전환, 재취업 준비 중 하나를 경험
- 전공 밖 강의·독학·프로젝트·아르바이트 중 하나 이상 보유
- 대표자 본인은 포함하지 않음
- 가능하면 배경이 겹치지 않도록 구성

권장 최소 구성:

- 전공과 희망직무가 다른 사람 1명
- 쉬었음 또는 공백 경험이 있는 사람 1명
- 비전공 학습·프로젝트 경험이 있는 사람 1명

### 상담사·기관 참여자

- 청년센터, 대학 진로센터, 여성새로일하기센터, 취업지원기관 중 한 곳
- 실제 초기상담 또는 교육과정 추천 업무를 수행
- 가능하면 도입 결정권자와 현장상담사를 구분해 기록

## 3. 동의와 개인정보 원칙

### 시작 전 읽을 문장

> 오늘 보실 것은 대회 준비 중인 비공개 샘플입니다. 취업 가능성이나 적성을 판정하지 않습니다. 이름·연락처·학교명·회사명·가족사·건강정보를 입력하지 않으셔도 됩니다. 관찰 결과는 익명 코드로 기록하고, 공개 인용은 별도로 동의한 문장만 사용합니다. 원하지 않으면 언제든 중단하거나 답하지 않을 수 있습니다.

### 반드시 따로 확인할 동의

- `[ ]` 화면 체험과 익명 관찰값 기록
- `[ ]` 익명 발언을 내부 개선에 사용
- `[ ]` 익명 발언을 대회 발표·방송·제출물에 사용 — 선택
- `[ ]` 화면 녹화 또는 음성 녹음 — 선택, 기본은 하지 않음

### 기록하지 않을 정보

- 실명, 연락처, 주민번호, 정확한 주소
- 가족 구성원의 실명과 민감한 가족사
- 건강·의료·범죄·정치·종교 등 민감정보
- 이력서 원문 전체와 비공개 회사자료

참여자 코드는 `Y01~Y05`, 상담사는 `C01~C02`로 기록한다.

## 4. 청년 사용자 15분 테스트

### 진행 원칙

- 기능을 먼저 설명하지 않는다.
- 막혀도 10초 동안 관찰한 뒤 최소한의 도움만 준다.
- “좋죠?” 대신 “무엇을 기대했나요?”라고 묻는다.
- 참여자가 한 말을 평가하거나 변명하지 않는다.
- AI 후보가 틀렸다고 말하면 즉시 이유를 묻고 수정·거절 행동을 관찰한다.

### 진행표

| 시간 | 진행 | 관찰할 것 |
|---|---|---|
| 0~1분 | 동의·익명코드 부여 | 동의 여부, 우려사항 |
| 1~2분 | 첫 화면만 보여주고 “무엇을 해주는 것 같나요?” | 목적 이해 문장 |
| 2~6분 | 본인 경험 또는 준비된 비식별 예시 입력 | 입력 부담, 민감정보 우려, 도움 횟수 |
| 6~9분 | 역량 후보 확인·수정·거절 | 틀린 후보, 원문 사용 여부, 수정 이유 |
| 9~12분 | 격차와 행동 하나 선택 | 행동의 현실성, 선택 이유 |
| 12~13분 | 카드와 Gap Brief 확인 | 신뢰도, 공유의향, 불편한 표현 |
| 13~15분 | 사후 질문 | 가장 유용·불편·빠진 것 |

### 참여자에게 줄 과업

> 최근 전공 밖에서 공부하거나 만들거나 일해 본 경험 하나를 떠올려 주세요. 서비스를 이용해 그 경험에서 인정할 수 있는 역량만 남기고, 이번 주에 할 행동 하나를 선택해 주세요. 진행자가 묻기 전까지 자유롭게 사용해 주세요.

### 관찰 기록

| 항목 | 기록 방식 |
|---|---|
| 목적 이해 | 참여자의 첫 설명을 그대로 요약 |
| 완료시간 | 시작부터 행동선택까지 분:초 |
| 도움 횟수 | 진행자가 방향을 알려준 횟수 |
| 후보 수 | 제안 / 확인 / 수정 / 거절 각각 개수 |
| 위험사례 | 원문에 없거나 과장된 후보를 확인으로 넘긴 사례 |
| 선택 행동 | 학습 / 프로젝트 / 상담 |
| 카드 신뢰도 | 1 전혀 못 믿음 ~ 5 매우 믿음 |
| 상담 공유의향 | 예 / 조건부 / 아니오와 이유 |
| 중단·오류 | 화면, 행동, 오류문구, 복구 여부 |

### 종료 질문

1. 이 서비스가 무엇을 해주는지 친구에게 한 문장으로 말한다면?
2. 가장 먼저 이상하거나 과장됐다고 느낀 표현은 무엇인가요?
3. 원문 인용을 함께 본 것이 판단에 어떤 영향을 줬나요?
4. 행동 3개 중 실제로 이번 주에 할 수 있는 것은 무엇인가요? 왜인가요?
5. 카드에서 타인에게 보여주고 싶지 않은 정보가 있었나요?
6. 평소라면 이 결과를 누구와 어떤 상황에서 사용하고 싶나요?
7. 한 가지만 없애거나 바꿀 수 있다면 무엇인가요?

## 5. 상담사·기관 20분 검증

### 보여줄 자료

1. 30초 문제·해결 설명
2. 서비스 데이터 흐름도
3. 청년 사용자 한 명의 5화면 흐름
4. 개인 카드와 Gap Brief
5. 동의·Lv.0~3·수정·삭제 규칙

### 현장 적합성 질문

1. 첫 상담 전에 현재 어떤 정보를 어떤 방식으로 받나요?
2. 그 정보를 읽고 재정리하는 데 보통 몇 분이 걸리나요?
3. Gap Brief만 받으면 어떤 질문으로 상담을 시작하시겠어요?
4. 과하거나 빠졌거나 오해를 만들 수 있는 표현은 무엇인가요?
5. Lv.0 자기기록과 Lv.1 연결증거의 구분이 현장에서 이해되나요?
6. AI가 절대 해서는 안 되는 판단은 무엇인가요?
7. 원문, 링크, 익명통계 중 기관이 실제로 받아야 하는 최소정보는 무엇인가요?
8. 수정·삭제·공유철회가 어떤 방식으로 확인되어야 하나요?
9. 상담 전·중·후 어느 시점에 이 도구를 쓰는 것이 가장 자연스러운가요?
10. 실제 파일럿을 한다면 어떤 청년 몇 명과 몇 주가 적당한가요?

### 사업화·구매 질문

1. 이런 도구를 도입할 때 현장사용자, 승인자, 개인정보 담당자는 각각 누구인가요?
2. 신규 소프트웨어 도입 대신 기존 프로그램 운영비·교육비로 실증할 수 있나요?
3. 구매 전에 반드시 필요한 보안·성과·접근성 자료는 무엇인가요?
4. 월 이용료, 상담사 계정료, 참여자 코호트 운영비 중 어떤 단위가 가장 자연스러운가요?
5. 금액을 묻기 전에 현재 비슷한 업무에 사용하는 시간·외주·프로그램 예산은 얼마인가요?
6. 유료 파일럿을 검토하려면 누구에게 어떤 자료로 제안해야 하나요?
7. 다음 대화를 이어갈 담당자와 가능한 날짜가 있나요?

가격을 먼저 제시해 동의를 유도하지 않는다. 현재 비용과 구매 단위를 들은 뒤에만 가격가설을 세운다.

### 상담사 평가표

각 항목 1~5점과 이유를 함께 기록한다.

- 문제 이해도
- Gap Brief의 첫 상담 유용성
- 근거등급 신뢰성
- 개인정보 통제 적절성
- 현재 업무흐름 적합성
- 파일럿 참여 의향

## 7. 세션 종료 후 10분 정리

1. 사실과 해석을 분리한다.
2. 참여자의 실제 발언과 진행자의 추론을 다른 칸에 적는다.
3. 문제마다 발생 화면·빈도·심각도·재현방법을 남긴다.
4. 한 사람의 요구로 기능을 추가하지 않고 다음 참여자에게 반복되는지 본다.
5. 다음 세션 전에 고칠 것은 P0·P1만 우선한다.
6. 공개 인용은 외부인용 동의가 있는 익명 문장만 별도 목록에 옮긴다.

## 8. 중단·실패 기준

다음 중 하나면 성공 수치를 계속 모으지 말고 원인을 고친다.

- 원문에 없는 후보가 화면에 나타남
- 사용자가 거절한 후보가 카드·Gap Brief에 남음
- 기록 삭제 후 입력 또는 파생결과가 다시 보임
- 동의하지 않은 원문이 기관 요약에 나타남
- 민감정보 입력을 유도하거나 저장했다는 오해가 반복됨
- 세션 중 실제 API 키·내부 오류정보가 노출됨

## 10. 결과를 발표에 쓰는 규칙

가능한 문장:

> 비공개 알파에서 청년 5명 중 4명이 15분 안에 행동을 선택했다. 표본이 작아 효과를 일반화하지 않고, 가장 많이 수정된 역량 표현과 막힌 화면을 다음 버전에 반영했다.

피해야 할 문장:

> GapProof가 쉬었음 청년의 취업률과 상담시간을 개선했다.
