## 3. RC 범위 판정 — 회원가입·이용량·초대 코드 (Gate 7)

**판정: RC에서는 "로컬 완전 세트 설계·구현·검증(비공개)"까지, 운영 데모의 접근 방식은 게이트 코드 유지.** 근거:

1. **법률 선행조건 미충족 상태의 공개 금지**: 실계정 수집을 시작하려면 /privacy·/terms가 실데이터 흐름과 일치해야 하고 전문가 검토 전 공개 가입은 위험. RC 일정 내 전문가 검토는 불가(외부 조건)
2. **운영 인프라가 Hard Stop**: 운영 Supabase 반영·이메일 발송 인프라(인증·재설정 메일)·카카오 콘솔 변경 전부 사용자 승인 필요 — RC 자율 범위에서 운영 공개 자체가 불가능
3. **부분 공개 금지 원칙**: 이메일 인증 없는 가입, 탈퇴 없는 계정 등 부분 세트 공개는 지시로 금지
4. 심사·멘토링 데모 목적에는 게이트+무저장 구조가 개인정보 리스크 최소로 부합

따라서 Gate 7 산출물 = ① 이 판정의 ADR ② Supabase 로컬 migration·RLS·테이블 8종 설계 파일 ③ 로컬 테스트 ④ 운영 전환 계획서(사용자 승인 게이트 명시). UI 공개 전환은 RC 이후 사용자 승인 항목.
