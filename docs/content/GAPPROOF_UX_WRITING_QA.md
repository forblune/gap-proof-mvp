# GapProof UX Writing QA 체크리스트 (Gate 0 초판)

문구 변경·신설 PR마다 아래를 통과해야 한다. Gate 9에서 전 화면 일괄 재검사.

## PR 단위 체크

- [ ] 새/변경 문구가 `GAPPROOF_VOICE_AND_TONE.md` 10원칙에 부합
- [ ] 용어 사전 표기와 일치(역량 후보/원문 근거/확인/증거등급/격차/이번 주 행동/데모 코드/샘플)
- [ ] 버튼 문구 = 실제 동작 결과 (클릭 후 일어나는 일과 1:1)
- [ ] 파괴적 작업은 명명 규칙 표의 4분류 중 하나를 사용, 확인창 3요소(무엇이 사라짐/비가역/두 선택지)
- [ ] `[필수]`/`[선택]`이 라벨 문자에 포함(색·아이콘 단독 금지)
- [ ] 오류 문구에 원인+다음 행동 포함, role=alert/status 적절
- [ ] 샘플 화면·결과에 "샘플" 표기 존재, 실연결에는 모델명
- [ ] AI 산출물에 "제안" 라벨, 확정 주체=사용자 서술
- [ ] 개인정보 관련 문구가 실제 동작만 서술(거짓 안전 보장 없음)
- [ ] 360px에서 버튼 줄바꿈·제목 어색한 줄바꿈 없음(스크린샷)
- [ ] 스크린리더 이름(aria-label/visible label)과 시각 문구 불일치 없음
- [ ] 인벤토리(`GAPPROOF_COPY_INVENTORY.md`)에 행 추가/상태 갱신

## 30초 이해 테스트 (Gate 2 산출물 대상, Gate 10에서 수행)

첫 방문자가 홈페이지만 보고 답할 수 있는가:
1. 이 서비스는 무엇을 하나요?
2. 누구에게 필요한가요?
3. 어떤 경험을 넣을 수 있나요?
4. AI가 무엇을 하고 사용자는 무엇을 결정하나요?
5. 어떤 결과를 받을 수 있나요?
6. 개인정보와 AI 결과를 어떻게 다루나요?
7. 현재 제공 기능과 예정 기능은 무엇인가요?

방법: 내부 콘텐츠 리뷰(각 질문에 답이 되는 섹션 지목) + 모바일/데스크톱 스크린샷 + 제목만 훑는 스캔 테스트(h1~h3만 읽고 7문항 답 가능한지) + 링크 없이 홈 안에서 핵심 전달 확인.

## 금지 목록 (발견 즉시 FAIL)

- 취업 가능성·적성·합격 판정을 암시하는 표현
- "완벽" "최고" "보장" "100%" 류 과장
- 미구현 기능의 현재형 서술
- 세션·토큰·캐시·바인딩 등 내부 용어의 앱 화면 노출
- 사용자를 탓하는 오류 문구("잘못 입력하셨습니다" → "코드가 올바르지 않아요")
- 저장되지 않는 것을 "기록"이라 부르거나, 저장되는 것을 숨기는 표현
