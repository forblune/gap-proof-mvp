# GapProof Voice & Tone (Gate 0 초판, 2026-07-25)

GapProof의 목소리: **차분한 동료 상담자.** 판정하지 않고, 과장하지 않고, 사용자가 한 실제 행동을 존중한다. "~해요"체 기본(정보 페이지 본문은 "~합니다" 혼용 허용), 명령형 최소화.

## 10원칙 (모든 문구에 적용)

1. **사용자 목적을 말한다** — 시스템이 하는 일이 아니라 사용자에게 일어나는 결과. ("초기화" ✗ → "새 분석 시작" ✓)
2. **내부 구현 용어 금지** — 세션·토큰·바인딩·폴백 같은 말은 화면에 쓰지 않는다. (기술 페이지는 예외, 단 풀어서)
3. **과장·판정 표현 금지** — "완벽한", "최고의", "당신은 ~에 적합" 금지. "판정하지 않습니다" 상시 고지 유지.
4. **필수·선택을 문자로 표시** — 색·별표에 의존하지 않고 `[필수]` `[선택]`을 라벨 문자에 포함.
5. **오류는 원인+다음 행동** — "실패했습니다" 단독 금지. 무엇이 왜 안 됐고, 지금 무엇을 하면 되는지 한 문장씩.
6. **같은 기능 = 같은 용어** — 용어 사전(아래) 밖의 동의어 혼용 금지.
7. **모바일 한 호흡 길이** — 버튼 ≤ 8자 내외, 안내 문장 ≤ 2줄(360px 기준), 제목은 줄바꿈 위치 고려.
8. **거짓 안전 보장 금지** — "안전하게 보관됩니다" 같은 검증 불가 약속 금지. 실제 동작(기기 내 보관·서버 미저장)만 서술.
9. **샘플과 실제 분석 구분** — 샘플 화면·결과에는 항상 "샘플" 표기. 실연결은 모델명과 함께 표기.
10. **AI보다 사용자가 최종 통제** — AI 산출물에는 "제안" 라벨, 확정 주체는 항상 사용자로 서술.

|---|---|---|

## 파괴적/상태 변경 작업 명명 규칙

이름은 기술 동작("삭제·초기화")이 아니라 **사용자가 얻는 결과**로 짓는다. 확인창은 "무엇이 사라지는가 + 되돌릴 수 없음 + 두 개의 명확한 선택지" 구조.

| 실제 동작 | 버튼 문구 | 확인창 |
|---|---|---|
| 현재 여정을 처음부터 다시 시작(입력·결과 모두 소거) | **새 분석 시작하기** | "새 분석을 시작할까요?\n현재 작성한 내용과 분석 결과가 사라집니다. 이 작업은 되돌릴 수 없습니다." → [계속 작성하기] [새 분석 시작] |
| 현재 입력만 비움(단계 유지) | 작성 내용 비우기 | 입력 20자 미만이면 확인 없이 즉시 |
| 샘플 체험 초기화 | 체험 처음부터 시작하기 | 확인 불필요(샘플은 사용자 작성물 아님) |
| 저장된 사용자 기록 영구 삭제(회원 도입 후) | 저장된 기록 영구 삭제 | 이중 확인 + 입력 확인 방식 |

## 상태별 톤

- **로딩**: 무엇을 하는 중인지 + 대략 시간. ("역량 후보를 찾는 중… 약 10초")
- **빈 상태**: 다음 행동으로의 초대. 자책 유발 문구 금지.
- **오류**: 사과 대신 사실+다음 행동. 남 탓(브라우저가~) 최소화.
- **성공**: 결과 확인 + 다음 단계 힌트, 감탄사 없이.
