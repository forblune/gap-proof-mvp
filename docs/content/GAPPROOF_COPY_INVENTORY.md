## §3. 검토 상태 집계

- 전수: ~450개 문자열 식별 완료(누락 후보: pii.ts 접미문 — §2 V에 등재)

- Gate 2~6 개편 대상 그룹(E·F 일부·K·L·M~P·T): 개편 구현 시 신규 문구를 본 인벤토리 원칙으로 작성 → Gate 9에서 전 행 최종 감사
- 적용 순서: Gate 1(만료 문구 — draft 보존 구현과 동시) → Gate 2~6(신규 화면 문구) → Gate 9(잔여 일괄 적용·최종 감사)
