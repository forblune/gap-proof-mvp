# 건희 역량·증거 프로필 — GapProof 방식 정리

> 이 대화에서 **건희님이 실제로 말한 것만** 근거로 정리했어요. GapProof 원칙 그대로 — 근거가 약한 건 "확인 필요"로 표시하고, 없는 건 지어내지 않았습니다. 이력서·포트폴리오·GapProof 자기 데모·발표 자기소개에 그대로 쓸 수 있어요.

---

## 1. 기록 (있는 그대로)

- **전공**: 항공물류학과 — 물류·공급망·항공 도메인
- **복수전공**을 시도했으나 막힘 → 전공 밖 학습을 스스로 찾아 연결해 옴
- **독학**: AI 수학, 웹 개발, 아두이노·라즈베리파이(임베디드), LLM/AI 활용(Upstage Solar 등)
- **산출물**: MindHub(Solar API 기반 한국어 상담 MVP, PBL 99점) · GapProof(진행 중, 라이브 배포)

## 2. 확인된 역량 후보 (근거 + 증거등급)

등급: **Lv.0** 자기기록 · **Lv.1** 근거 연결 · **Lv.2** 수행 확인 · **Lv.3** 기관 확인

| 역량 | 근거 (대화 기반) | 등급 | 더 붙이면 강해지는 것 |
|---|---|---|---|
| AI·API 기반 서비스 프로토타이핑 | Solar API로 MindHub·GapProof를 실제 제작하고 **라이브 배포**(gapproof.forblune.com) | **Lv.2** 수행 확인 | 3분 데모 영상, 사용자 테스트 |
| 도메인×기술 융합 문제정의 | 항공물류 전공을 AI·웹과 연결해 서비스 문제로 재정의 | Lv.1 근거 연결 | 문제정의 1장 문서화 |
| 풀스택·클라우드 배포 | Cloudflare Workers 배포 + 커스텀 도메인·DNS·시크릿·GitHub 레포 | Lv.1~2 | 배포/CI 파이프라인 기록 |
| 제품 기획·전략 | 자립형 전환, 두 트랙 정렬, B2G2C 모델, MVP 범위 결정 | Lv.1 근거 연결 | 사용자 인터뷰로 검증 |
| 자기주도 학습 | 전공 밖 AI·웹·임베디드를 스스로 학습, 막혀도 대안 경로 탐색 | Lv.0~1 | 수료·노트·산출물 링크 |
| 보안·개인정보 감수성 | 접근 코드 게이트·레이트리밋·개인정보 마스킹·적대적 리뷰 반영 | Lv.1 | OWASP/보안 점검 기록 |
| 임베디드·하드웨어 기초 | 아두이노·라즈베리파이 학습 | Lv.0 자기기록 | 작동 회로/코드 |

## 3. 커리어로 될 만한 방향 (목표직무 후보)

- **스마트물류·물류테크 서비스 기획/개발** — 항공물류 전공 × 디지털·AI. 가장 "건희님다운" 융합. **(강)**
- **AI 서비스 기획자(AI PM)** — 도메인+AI+기획+프로토타이핑 조합. **(강)**
- **풀스택·AI 애플리케이션 개발 입문** — MindHub·GapProof·배포 경험 기반. (중)
- **공공·에듀테크 진로/역량 서비스 PM** — GapProof 자체가 포트폴리오. (중)

## 4. 다음 성장 지점 (지금 붙이면 확 강해짐)

- **사용자 검증**: MindHub/GapProof를 실제 5~10명에게 써보고 인터뷰·수정 기록 남기기
- **성과지표**: 사용률·완료율 등 숫자로
- **협업·팀 경험** 증빙과 회고
- **포트폴리오화**: GitHub README + 3분 데모 영상 + 라이브 URL 정리
